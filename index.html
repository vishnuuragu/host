03 PROTOCOL

How it works

Three rules govern every module in the system.

01

Pick a module

Each app is its own folder: one HTML file, one stylesheet, one script — drawing on a single shared design core. Nothing is bundled.

02

It runs instantly

No build step, no install, no server round-trips. The browser is the whole runtime — click a card and you're in.

03

Your data stays yours

Everything persists to localStorage on your own device. There is no backend, no account, and nothing leaves the page.

Pick a module and go.

Everything runs in your browser, right now — no sign-up, no install, no waiting.
